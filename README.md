# Rekap Nilai Mahasiswa

## Deskripsi
Website Rekap Nilai Mahasiswa dibuat menggunakan PHP dan MySQL untuk mengelola data nilai mahasiswa.

## File Utama
- `viewdata.php` — menampilkan data mahasiswa.
- `insertdata1.php` — memproses penambahan data mahasiswa.
- `editdata1.php` — memproses perubahan data mahasiswa.
- `deletedata.php` — memproses penghapusan data mahasiswa.
- `connection1.php` — mengatur koneksi database.

## Fitur
1. CRUD data mahasiswa.
2. Pencarian data berdasarkan nama.
3. Pengurutan data berdasarkan NIM, nama, dan nilai akhir.
4. Filter berdasarkan predikat.
5. Pagination.
6. Upload dan penggantian foto mahasiswa.
7. Perhitungan nilai huruf dan predikat otomatis.
8. Informasi tanggal pembuatan dan perubahan data.
