Rekap Nilai Mahasiswa

Deskripsi
Website Rekap Nilai Mahasiswa dibuat menggunakan PHP dan MySQL untuk mengelola data nilai mahasiswa.

File Utama
- `viewdata.php` — menampilkan data mahasiswa.
- `insertdata1.php` — memproses penambahan data mahasiswa.
- `editdata1.php` — memproses perubahan data mahasiswa.
- `deletedata.php` — memproses penghapusan data mahasiswa.
- `connection1.php` — mengatur koneksi database.

Fitur
1. CRUD Data Mahasiswa: Menambahkan, melihat, mengubah, dan menghapus data mahasiswa.
2. Pembacaan Data Foto: Menampilkan foto mahasiswa di sebelah nama mahasiswa.
3. Pencarian Data: Mencari data mahasiswa berdasarkan nama.
4. Filter Predikat: Menyaring data mahasiswa berdasarkan predikat.
5. Sorting Data: Mengurutkan data berdasarkan NIM, Nama Lengkap, dan Nilai Akhir secara ascending (ASC) maupun descending (DESC).
6. Pagination: Mengatur jumlah data yang ditampilkan per halaman dengan pilihan 5, 10, 15, dan 20 data.
7. Pengolahan Nilai: Menampilkan nilai akhir, nilai huruf, dan predikat mahasiswa secara otomatis.
8. Informasi Tanggal: Menampilkan tanggal pembuatan dan perubahan data mahasiswa.
